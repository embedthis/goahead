webcomp [--strip prefix] fileList >output.c

DESCRIPTION
       To enable files to be accessed on embedded systems without a file
       system, the webcomp command converts arbitrary files into C code that
       can be compiled and linked into a program. This is useful for
       applications that must execute completely from ROM and not access a
       file system.  This facility can also enhance security by preventing the
       modification of files.

       The fileList argument names a file that lists the pathnames of the
       files to convert, one per line. The C source is written to the standard
       output.

       When GoAhead is built with ME_ROM enabled, it serves documents from the
       compiled files instead of the file system. Link the generated source
       into the program.

OPTIONS
       --strip prefix
              Specifies a prefix to remove from each of the compiled file
              names. The --prefix option is an alias for --strip.

EXAMPLE
       This example lists the documents directory, its subdirectories and
       files, and the route and authentication files, and converts them into C
       structures in the file romFiles.c. A ROM build reads route.txt and
       auth.txt from the compiled files too, so list them. List each path as
       the server names it: the documents under the documents directory, here
       web, and the configuration files relative to the directory the server
       runs in. Do not strip the documents directory, since the server looks
       documents up beneath it.


           find web route.txt auth.txt -print >fileList

           webcomp fileList >romFiles.c

           cc -o romFiles.o romFiles.c
