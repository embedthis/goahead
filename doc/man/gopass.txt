NAME
       gopass - Create and manage passwords

SYNOPSIS
       gopass [--cipher blowfish|md5] [--file filename] [--password password]
       [--rounds count] realm username roles...


DESCRIPTION
       The gopass program creates authentication passwords for GoAhead in the
       nominated authentication configuration file.  GoAhead uses the same
       authorization file and format for Basic, Digest and web-form
       authentication. This simplifies           administration.

            gopass --file auth.txt example.com admin administrator buyer

       gopass prompts for the password and asks for it twice.

       gopass writes the stored credential, not the password. With the
       default cipher it writes a Blowfish hash in the BF2 format
       (BF2:rounds:salt:hash); with --cipher md5 it writes the MD5 of
       username:realm:password, which Digest authentication requires and
       which is a password equivalent: anyone who reads it can authenticate
       with Digest without knowing the password. The realm must be the one
       the server is built with (ME_GOAHEAD_REALM, example.com by default),
       because it is part of every hash. The file is created mode 0600 and
       must stay readable by the server account only. Passwords are at most
       ME_GOAHEAD_LIMIT_PASSWORD (32) characters. Releases before 6.2.0
       cannot verify a BF2 hash.

       To calculate the password only, omit the "--file" option and the
       password will be displayed to the standard output.

            gopass example.com admin administrator buyer


OPTIONS
       --cipher blowfish|md5
              Specifies the cipher to use to hash the password. Default is
              blowfish. Blowfish is substantially more secure.  MD5 must be
              used for digest authentication.

       --password password
              Specifies the password for the user. Without this option, gopass
              prompts for it. A password given on the command line can be seen
              by other local users in the process list and is kept in the
              shell history, so prefer the prompt.

       --file filename
              Update the specified password configuration file.

       --rounds count
              Sets how many times a Blowfish hash runs the Blowfish key
              schedule, from 1 to 65536. Default is 128. The time to check the
              password, at each login and for anyone guessing it from a copy
              of the file, grows in proportion. GoAhead is single threaded, so
              each login holds other requests for that time.

DESCRIPTION
       The gopass program is used to create and manage user passwords.
       GoAhead uses the same authorization file and format for Basic, Digest
       and Post authentication stores. This simplifies administration.
